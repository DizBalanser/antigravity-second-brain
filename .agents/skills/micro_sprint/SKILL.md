# Micro-Sprint Skill (Anti-Procrastination Engine)

## Concept
Action precedes motivation. When overwhelmed by a massive task or feeling stuck, standard to-do lists cause friction and avoidance. A 15-minute micro-sprint lowers the activation energy to zero: commit to ONLY 15 minutes of work without distractions.

## Triggers
- User says "I can't get started", "procrastinating", "don't know where to begin".
- User has high-priority tasks pending for more than 48 hours.
- Direct invocation via `/sprint [minutes] [task]`.

## Execution
1. Slice the monster: Break the task down into a trivial 2-minute entry step (e.g., "just open the IDE and write 1 function docstring", "open the draft and write bullet points").
2. Set a timer: Schedule a notification in exactly 15 minutes.
3. Eliminate all friction: Tell the user: "Close all tabs except this one. Full focus for 15 minutes. I will ping you when time is up."
4. Check-in & Momentum: When the timer rings, ask: "15 minutes done! Did you gain momentum? Want to lock in another 15 minutes or wrap up this block?"
